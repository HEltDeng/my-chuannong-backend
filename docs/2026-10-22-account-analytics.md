# 账号日活与设备资料

新增超级管理员入口「用户与活跃统计」，并在川农工作台展示四张活跃卡片。保留绿色主题、原有板块工作台与账号治理功能。

## 口径

- 北京时间自然日；DAU 为当日发生成功注册、登录、主动业务操作或授权前台上报的可用 PHONE 账号，跨设备去重。WAU/MAU 分别含今日的7/30个自然日，另列本自然月。
- 游客、管理员、后台 APP_ACTIVE 轮询、失败操作、当前禁用/注销账号均不计入。当前 LIMITED 账号仍可浏览，计入可用账号。
- 迁移旧日志只取当时已归属 USER 身份的成功业务事件；不会把设备匿名历史归到后来的登录账号。迁移幂等，未观测历史显示空缺，不制造历史日活。
- 新注册账号数排除已注销账号。当前没有短信核验，手机号与型号均不能证明唯一自然人；指标显示「账号」而非「已核验真实人数」。

## 实现与权限

`account_analytics.py` 适配迁移自 `HEltDeng/my-changli-backend` 提交 `d069aeb814f041414e5c7da76d414acb93416e9b` 的成功业务事件白名单与北京时间窗口定义；未迁移另一产品的数据库、密钥、账号、学校身份或生产配置。

`account_activity_daily` 按账号/日期唯一，`account_device_profiles` 按账号/安装关联。`POST /api/v1/activity/foreground` 只接受已登录平台账号及版本3的政策同意声明，服务端决定日期；不接受任意客户端时间。重试、多设备和切换账号不会增加同一账号当日日活。客户端声明并非硬件证明，系统不宣称能防止恶意账号伪造设备。

`GET /api/v1/admin/account-analytics?days=7|30|90` 与 `/accounts?window=today|7d|30d|month` 只开放 SUPER_ADMIN。按日明细使用 `window=day&day=YYYY-MM-DD`，每页50条。手机号脱敏，不返回原始设备标识；型号缺失显示未上报。

活跃日明细按天保留180天，型号资料在最后上报180天后清理；启动、统计读取、前台上报及生产每小时维护执行清理，注销直接删除关联记录。原数据库备份保留机制不改变。

## 客户端与验证

安卓提升政策同意版本为3；主界面使用既有账号登录组件，学校认证流程保持独立。前台生命周期与账号状态驱动上报，每5分钟节流、跨日/换号重报；退出、后台、未同意时不发，失败不重放历史。字段包括安装标识、原有派生设备标识、厂商/型号、系统与APP版本。注册手机号使用用户填写信息，无新增电话、通讯录或短信权限。

接口与数据库使用隔离合成数据验证去重、跨日/月、权限、同意版本、分页、旧数据迁移、删除和保留期。完整后台127项测试通过；本地浏览器验收卡片与明细一致，图表7/30天切换正常、控制台无错误。正式 APK 尚未生成，待高德企业认证与正式Key后再构建；旧 APK 不会自动拥有新的前台型号上报功能。
