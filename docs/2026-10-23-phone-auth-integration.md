# 手机号、学号与账号统计接入

状态：本地实现与验证完成，未部署。iOS / Android 已接入注册验证码、确认密码、找回密码、存量手机号验证、学生资料提交及当前协议收据。腾讯云已完成企业认证并开通短信；本轮控制台核对仍有免费 200 条，已取消此前待付款订单。国内套餐余量提醒已保存为 500 条，自动续订已保存为低于 100 条购买 1,000 条。公司盖章材料待补齐，短信资质、签名及模板待审核；未创建发送密钥，未实发短信。

本轮与生产隔离。部署前必须同步客户端版本：服务端新注册接口要求验证码证明，旧客户端不支持新注册契约；现有手机号密码登录契约保留。

## 用户确认的业务规则

- 注册验证手机号，日常使用手机号和密码登录；找回密码时发送验证码。
- 每个账号每天最多两次找回，按北京时间自然日恢复，不删除账号。
- 注册、重置密码均重复输入密码；客户端显示每日次数和次日恢复规则。
- 一个学号只绑定一个平台账号及手机号；各端和各业务板块共用账号，不提供自由换绑。
- 姓名、学号、手机号归于同一用户档案。姓名、学号和手机号加密存储；超级管理员可查看完整资料。
- 学校密码、Cookie、课表、成绩和学校登录会话不上传平台。
- 同一账号重复安装、多设备登录不增加注册人数；DAU 按用户 ID 和北京时间日期去重。
- 手机验证码证明当前持有手机号，不证明学生身份；自行填写姓名和学号只产生待核验记录，不计入已核验学生人数。当前提供超级管理员凭独立依据核验的入口，尚无学校签名认证接口。

## 腾讯云准备

腾讯云设置：国内短信套餐余量低于 500 条提醒；低于 100 条自动续订 1,000 条。当前标准价每次 50 元，费用从腾讯云账户余额扣除，余额不足会失败。自动续订是预付费购包，不是超额后付费。免费包已在控制台核对为 200 条，截止 2027-01-23；当前不再另建付费订单。

申请本公司自用公司签名，具体值从本机私有档案读取并在腾讯云填写，不存入仓库。创建验证码模板：

- 注册模板草稿：`您正在注册我的川农，验证码{1}，{2}分钟内有效，请勿向他人泄露。`
- 重置模板草稿：`您正在找回我的川农密码，验证码{1}，{2}分钟内有效，请勿向他人泄露。`
- 存量手机号验证模板草稿：`您正在验证我的川农账号绑定手机号，验证码{1}，{2}分钟内有效，请勿向他人泄露。`

模板参数顺序为 6 位验证码、有效分钟数 5。必须在腾讯云签名、模板审核及运营商报备可用后测试。发送签名加正文应控制在单条计费长度以内。注册、重置和存量手机号验证分别使用对应模板，不复用用途。

## API 契约

当前协议版本 `2026-10-23.2`；需要同意收据的请求包含 `policyVersion`、毫秒时间戳 `consentAcceptedAt`。客户端必须显示对应实际协议并记录用户同意；不能伪造收据或后台默认同意。

| 接口 | 请求 / 行为 |
|---|---|
| GET /api/v1/auth/capabilities | 公开返回可用用途、码长、过期时间、重发间隔、找回上限、协议版本；不返回密钥或模板 ID。未配置时可用用途为空。 |
| POST /api/v1/auth/sms-code | phone、purpose（register / reset / verify_phone）和同意收据；返回 challengeId、过期和重发间隔；不返回验证码。verify_phone 要求当前账号登录。 |
| POST /api/v1/auth/register | phone、password、confirmPassword、challengeId、code、同意收据及原安装字段；成功返回现有 token / user。 |
| POST /api/v1/auth/login | 现有手机号密码登录；不每次发短信。 |
| POST /api/v1/auth/reset-password | phone、password、confirmPassword、challengeId、code 和同意收据；返回 remainingToday，撤销原会话，重新登录。 |
| POST /api/v1/auth/verify-phone | 登录态、challengeId、code 和同意收据；手机号取当前用户记录。 |
| PUT /api/v1/auth/student-identity | 登录态、schoolCode=SICAU、studentId、realName 和同意收据；加密保存并置 PENDING。禁止附带学校凭证。 |
| POST /api/v1/admin/users/{id}/student-review | 超级管理员；action=approve/reject、reason。通过后 VERIFIED；驳回释放错误绑定。依据加密保存，审计仅记录结果及引用。 |
| GET /api/v1/admin/phone-auth | 超级管理员查询是否配置及当日请求、腾讯云接受量、计费分段数、完成验证数。 |

验证码 5 分钟有效，错误输入最多 5 次，单次消费；60 秒重发间隔。短信发送限制、验证码消耗和密码找回次数持久化到 SQLite；并发消费受写事务保护。网络结果未知时不自动重发，避免重复扣费。发送次数限制包含已提交失败和结果未知的请求；配置缺失时释放预留记录，不消耗验证码日额度。普通登录不要求每次发送短信。

账号用户对象增加 `phoneVerified`、`studentId`、`realName`、`identityStatus`。姓名学号仅返回本人及授权的超级管理员，不返回给广告主。广告展示使用汇总统计，需区分注册账号、验证手机号账号、核验学生、活跃账号，不把设备安装数声称为真实人数。

## 本地完成范围与验证

- 两端共用相同 API、用途和字段：注册自动登录，重复确认密码，短信 60 秒重发间隔、5 分钟有效，输入六位验证码；iOS 使用系统一次性验证码填充，不读取收件箱。
- 密码找回成功后撤销原平台会话；两端提示重新登录及当天剩余次数。超过限制次日恢复，不删除账号。
- 存量用户从账号与安全进入绑定手机号验证。学生资料页提交姓名和学号，服务端要求手机号已经验证；重复学号或修改已绑定资料返回明确错误。资料先标记待核验，后台凭独立依据处理。
- 后台用户列表同列显示完整手机号、姓名、学号；核验权限限制在超级管理员。统计区分注册、手机号验证和已核验学生，DAU/WAU/MAU 按账号 ID 去重。
- 缺少配置时客户端显示实际不可用状态并禁用发送，不伪造发送成功；没有发布版固定验证码或绕过核验接口。
- 登录/注册/重置/验证、设置中的品牌小图标及后台图标统一使用新版绿色叶子。
- 后端 156 项测试通过；安卓 Release 编译与 375 项 JVM 测试通过；Swift 核心 41 项测试通过，iOS 模拟器编译和 3 项实际 UI 用例通过。UI 用例验证手机号长度、密码不一致提示、未配置短信时发送禁用、登录/注册/重置/验证页面。后台用合成账号实测了核验保存及统计更新，修复弹窗切换导致保存失效的问题。真实短信发送尚未验收。

## 配置及协调上线步骤

1. 用户补齐盖章材料后，申请短信资质、公司签名及上述三个模板。企业实名认证通过不等于短信签名和模板已可发送。
2. 审核通过后取得 `SmsSdkAppId`、签名、三个 `TemplateId`，使用最小权限的腾讯云发送凭证。密钥只写服务器仓库外环境文件，参照 `sms.env.example`；禁止放进 APP、Git、日志或聊天。
3. 上线前备份现有数据库及加密/摘要密钥。不要更换既有 PII 加密密钥或 phone-hash 密钥；迁移在原库增列建表，不重建账号。保持真实业务板块开放状态。
4. 后端和新客户端安排同一发布窗口，旧版注册入口会因缺少验证码被拒绝，需事先提供升级入口。旧账号可继续用原密码登录并按新页面完成手机号验证。
5. 重启后核对 `/api/v1/auth/capabilities` 包含三种用途，后台“短信验证”显示已配置；该状态仅证明变量完整，不代表腾讯云审核或最终送达。
6. 在用户指定的本人手机号上，分别测试注册、存量验证及找回；核对腾讯云回执和计费，验证旧会话失效、重复验证码拒绝、每日次数及不同端同账号统计。失败按供应商错误处理，不自动重发未知结果。
7. 再验收客户端和后台，确认后发布。后台本轮代码、APP 和图标改动尚未上传 GitHub、发布或部署到生产。

本地运行仍用已有 `run_local.py` 和仓库外开发凭据，默认 `127.0.0.1:8792/admin/`。本轮额外的 `127.0.0.1:8794/admin/` 仅用于合成数据界面检查，不是生产入口；其测试凭据和数据库位于本机临时目录，不进入仓库。
