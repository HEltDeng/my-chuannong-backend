# 2026-10-22 板块运营与关注通知

本次按用户要求扩展各板块的实际管理功能。原学校认证、教务抓取及学校凭据仍只在手机处理。

## 实现

- 二手、失物招领：管理员直接发布、图片上传、原有审核/下架/删除；提交幂等，删除后重试不会复活帖子。
- 驾校、雅思托福、考公考研、健身房：独立后台入口，机构内容、图片、发布状态及本板块预约管理。
- 跑腿代取、后勤报修、电费指南：独立入口与对应管理角色。
- 资料库、失物招领保留原有专属角色。超级管理员可创建、编辑各板块管理员；越权读取、修改、公告发布和预约联系人访问均由服务端阻止。
- 每个板块可单独发布动态及图片。通知与弹窗默认关闭，只针对主动关注该板块的用户。
- 新增 `/api/v1/notifications/follows`、`PUT /api/v1/notifications/follows/{module}`、`/api/v1/notifications/feed`。关注记录绑定平台账号；默认全关，只返回关注之后发布的新动态，取消关注立即排除，注销账号清除记录。
- 公共 bootstrap 继续提供浏览内容，但通知/弹窗标志固定关闭，避免旧客户端群发。安卓通过新的鉴权通知流处理提醒。

## 验收

本地后端 117 项测试通过；JavaScript 语法检查通过。新增覆盖角色隔离、预约联系人保护、发布与删除幂等、跨板块公告、图片、默认不通知、取消关注、跨账号隔离及账号注销。

Chrome 隔离数据库验收通过二手发布、驾校图片加载、驾校管理员专属入口与板块动态发布；测试数据未写入生产数据库。

## 部署

先在服务器普通用户下对源码包运行隔离测试，然后用 `scripts/upgrade-module-operations.sh ARCHIVE SHA256 RELEASE EXPECTED_CURRENT` 执行升级。脚本需要 root：核对当前版本及包 SHA-256、校验归档内容、确认依赖未变、停止川农服务、备份并验证数据库、原子切换代码、启动并检查 readiness，失败自动回退代码。

只增加表/列，回退代码不恢复旧数据库，避免覆盖新写入。备份保留在服务器专用备份目录，未进入源码包。本脚本不改其他产品、Nginx、凭据或 systemd 配置。

`docs/delivery/accepted-source-manifest.json` 是 10 月 21 日的历史验收快照，保留不改；当前有意开发改动不能用旧校验器冒充原快照验收。部署归档使用新 Git 提交和独立 SHA-256。
