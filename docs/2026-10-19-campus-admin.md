## 本机使用

1. 在后端仓库运行 `./start-local.ps1`，打开 `http://127.0.0.1:8792/admin/`。
2. 沿用本产品仓库外的 `MY_CHUANNONG_LOCAL_CREDENTIALS` 配置；默认依次检查旧的专用位置与当前用户 `.codex/private/my-chuannong/backend-local.json`。首次使用另一台电脑需按 `START_HERE.md` 创建独立配置，不能复用长理配置。
3. 后台采用川农图标、绿色主题、运营模块分组和窄屏横向导航。本机配置 Revision 2 / Config V2 已激活，上一版本可回滚。
4. 「机构与课程」中保留一个明确标记的驾校配置示例草稿。未发布、未开放预约；真实机构信息需运营填写后发布。三个服务指南默认草稿。
5. APP 新代码通过固定产品地址的原生接口连接后台。已有版本必须换装本次重新构建的 Debug APK。手机连接本机后执行 `adb reverse tcp:8792 tcp:8792`；断开调试后不能访问本机服务。

## 接口与数据边界

- 用户接口：`/api/v1/community/{secondhand,lost-found}`、`/api/v1/services/{providers,bookings,guides}`。
- 管理接口：`/api/v1/admin/campus/{summary,catalogue,secondhand,lost-found,providers,bookings,guides}`。
- 使用既有平台身份会话。WebView 仅开放对应模块白名单方法；页面不获得令牌，也不能指定外部地址。上传图片通过固定后台地址读取。
- 二手和失物的本机示例、历史记录不会自动上传。初次连接不可用时可继续明确标记的本机模式；联机提交失败不会写入本机并假称发布成功。
- 联系方式与预约姓名、电话加密存储；本人权限、运营角色、幂等创建、预约状态转换和操作审计由后端验证。演示或未发布机构不能预约。预约是待确认的意向登记，不收款、不代表已确认名额。
- 账号注销清理新模块的内容、图片和预约个人信息。学校密码、验证码、Cookie、学校令牌、课表和成绩均不进入后台。
- 新表通过 `CREATE TABLE IF NOT EXISTS` 添加，原有记录保留；数据库与备份不进入 Git。
